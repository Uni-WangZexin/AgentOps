## 分类规则

1. **异常类别**：intra-agent包括推理、动作、记忆、安全；inter-agent包括任务规范、编排、通信、终止。来自§II。
2. **方法路线**：检测/缓解保持Table V的类别与D/M标记；根因定位按§VI；处置机制按§VII的干预时间排列。
3. **论文主类**：首页为每条研究记录选择一个主要检索位置。这是基于综述用途的目录编排，不是声称作者为每篇文献制定了唯一类别。
4. **交叉关联**：Paper list允许一篇文献属于多个相关类别；表示用途或讨论相关，不等于该方法已经验证了每种异常。
5. **数据集覆盖**：保留Table IX原始映射，不从文献的导航标签推导数据集标签。
6. **正交维度**：执行前、中、后是时间维度，不能与intra-/inter-agent合并成互斥分类。

主类与关联类别分别存于 [papers.json](../data/papers.json) 和 [catalog-rules.json](../data/catalog-rules.json)，每条研究记录保留综述引用位置。

## 去重与来源类型

- CoT的[16]/[104]指向同一论文，研究目录合并为一条，保留两个原始编号。
- [31]/[117]属于相关版本，现有证据下保留两条；98不等于98项完全独立研究贡献。
- 工具文档、模型卡、博客和白皮书单列，不计入研究文献数量。
- 年份与会议/期刊默认采用综述字段。题名版本变化、预印本年与会议年混用等差异保留在[完整引用索引](references.md)。

## 资源字段

| 字段 | 含义 |
| --- | --- |
| Paper | 原论文入口：arXiv、出版社或会议页面 |
| Project | 既有核验记录中的作者/官方项目；不等于代码已实测可运行 |
| Data | 数据托管或官方提供的下载入口，访问条件另记 |
| — / 未提供 | 当前未获得该字段，不意味着资源不存在 |
| D / M | 综述的检测/缓解标记，不是本仓库测得的性能 |

中文简介来自综述引用语境、题名和既有来源核验，不是逐篇全文精读。没有猜测新增代码仓库，也不镜像benchmark数据。

## 数据口径

`#Fail.`混用了任务、轨迹和错误实例，本目录显式标单位。TRAIL的841和AEGIS的24,843是错误数；LongRCA的200条Mini属于1,140条全量中的子集。MP-Bench论文与代码文档的数量差异分别记录。

`Single RC`和错误标签数量不同；`Scalability`保留原文定性字段。详细来源、许可和访问条件见 [Datasets](../datasets/README.md)。

## 维护

基础引用与核验信息在`data/references.json`、`data/reference-verification.json`；数据集与工具使用`data/datasets.json`、`data/monitoring-tools.json`。类别映射和生成逻辑在`scripts/build_catalog.py`。更新后运行：

```bash
python3 scripts/build_catalog.py
python3 scripts/validate.py
```

新增原文以外的资源应另开扩展分类，不占用1–125的编号。校验只检查本地目录、引用和导航，不代表实验复现。
